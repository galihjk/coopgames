NEBULA DUO - DAFTAR FILE SUARA

Buat folder bernama: sounds
Letakkan folder tersebut di lokasi yang sama dengan file nebula_duo_mobile_game.html.

Struktur:
nebula_duo_mobile_game.html
sounds/
  player-shoot.mp3
  enemy-shoot.mp3
  hit.mp3
  explosion.mp3
  player-down.mp3
  pickup.mp3
  boss-warning.mp3
  upgrade.mp3
  level-complete.mp3
  game-over.mp3
  button.mp3
  background-music.mp3

Keterangan dan saran durasi:
1. player-shoot.mp3
   Tembakan laser ringan pemain. Sangat pendek, sekitar 0,05-0,15 detik.

2. enemy-shoot.mp3
   Tembakan energi musuh. Pendek, sekitar 0,10-0,25 detik.

3. hit.mp3
   Pesawat pemain terkena serangan. Sekitar 0,10-0,30 detik.

4. explosion.mp3
   Ledakan musuh. Sekitar 0,20-0,70 detik.

5. player-down.mp3
   Ledakan besar saat pesawat pemain hancur. Sekitar 0,70-1,50 detik.

6. pickup.mp3
   Suara mengambil heal/pickup. Sekitar 0,20-0,60 detik.

7. boss-warning.mp3
   Alarm/peringatan kemunculan boss. Sekitar 1-2 detik.

8. upgrade.mp3
   Suara konfirmasi pemilihan upgrade. Sekitar 0,30-0,80 detik.

9. level-complete.mp3
   Jingle kemenangan level. Sekitar 1,50-3 detik.

10. game-over.mp3
    Jingle kekalahan. Sekitar 1,50-3 detik.

11. button.mp3
    Klik tombol menu. Sekitar 0,05-0,20 detik.

12. background-music.mp3
    Musik loop sci-fi/arcade tanpa jeda yang terasa jelas. Disarankan 45-120 detik.

Catatan:
- Nama file harus sama persis.
- Format MP3 paling mudah digunakan di browser mobile.
- Game tetap dapat dimainkan walaupun file suara belum tersedia.
- Hindari suara tembakan yang panjang karena dapat bertumpuk saat fire rate tinggi.
- Pastikan file memiliki lisensi yang mengizinkan penggunaan pada proyek Anda.
